## 🐾 PetIsFamily

## 🔍 Project Description

**PetIsFamily** is a modern pet adoption platform where users can explore, search, and adopt pets easily. The platform allows pet owners to list pets for adoption, while adopters can browse available pets, filter them, and send adoption requests. It includes authentication, profile management, and a smooth user experience with a responsive UI.

| **Authentication** | BetterAuth (configured with MongoDB Adapter) |


## Key Features of this Project

* Browse and search available pets with filters (species, name, sorting)
* Secure authentication system using BetterAuth
* Post pets for adoption with detailed information
* Adoption request system with approval/rejection workflow
* Dynamic pet details page with full information
* User profile management and protected routes
* Responsive modern UI with Tailwind CSS + HeroUI
* Real-time updates using server-side fetching
